# NEXO

A personal learning workspace for planning, tracking, and reflecting on daily study.

## Features
- Dashboard for daily study time, completion, weekly activity, and subject breakdown
- Date-based study planning and task checklist
- Study log with subject filters and deletion
- Daily reflection and reflection archive
- Personal pathway research notes
- Skill roadmap for mathematics, information/AI, economics/finance, and English
- Personal notes with categories and editing
- Dark/light theme
- JSON backup export and import
- Responsive layout and installable PWA

## Deploy with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment to finish.

## Privacy
This is a static frontend. Study records and notes are stored in the browser's localStorage; they are not uploaded to a server or synced across devices. Clearing browser data may erase them, so use the JSON backup feature regularly.

**Important:** Because the site is public, its HTML, CSS, and JavaScript can be viewed by anyone. Do not enter passwords, secrets, or highly sensitive information. Browser-local storage is not an authentication or access-control system.
